# Distributed Backup System using TCP and SDN

## Project Overview
A distributed backup application that transfers files
from clients to multiple backup servers using TCP.

Software Defined Networking (SDN) dynamically selects
suitable network paths and supports recovery during failures.

## Features
- TCP-based file transfer
- File chunking
- Checksum-based integrity verification
- Interrupted transfer recovery
- Multiple backup servers
- Dynamic SDN path selection
- Network failure simulation
- Throughput and recovery time measurement

## Technology Stack
- Ubuntu
- Python
- TCP Sockets
- Mininet
- Open vSwitch
- Ryu SDN Controller
- Git and GitHub
